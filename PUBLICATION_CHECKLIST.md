# GitHub Publication Checklist

Use this checklist before making the Cassandra repository public.

- [ ] No `.env` files are committed.
- [ ] No API keys, SSH keys, or access tokens are committed.
- [ ] No private customer data is committed.
- [ ] No model weights are committed unless intentionally released.
- [ ] Benchmark language is labeled as internal/preliminary where appropriate.
- [ ] README clearly says weights are not included.
- [ ] Repository visibility is private until legal and release review is complete.
- [ ] Public benchmark claims have prompt sets, scoring scripts, model hashes, and hardware settings.

## Suggested GitHub Repository Name

`cassandra-t1-model-architecture`

## Suggested Description

Public architecture notes, information architecture, demo interface, and benchmark methodology for Cassandra T1, a SophiaXT masked diffusion language model.
